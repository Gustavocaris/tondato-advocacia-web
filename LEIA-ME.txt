SITE TONDATO ADVOGADOS ASSOCIADOS
=================================

Tecnologia
  Next.js (App Router) + React + TypeScript. Blog preparado para o Sanity.io.

Estrutura
  src/app/              Páginas e layout
    layout.tsx          Cabeçalho, rodapé, fontes, SEO (meta tags e JSON-LD)
    page.tsx            Página inicial (monta as seções)
    blog/page.tsx       Lista de artigos (/blog)
    blog/[slug]/        Página de cada artigo (/blog/nome-do-artigo)
    globals.css         Visual e responsividade (desktop, tablet e celular)
  src/components/       Uma seção do site por arquivo (Hero, Servicos, Sobre,
                        Duvidas, Contato, BlogSection, BlogCard...)
  src/lib/site.ts       Telefone, e-mail, endereço e links do menu
  src/lib/blog.ts       Acesso aos artigos (hoje dados de exemplo; depois Sanity)
  src/data/posts.ts     Artigos de exemplo
  src/types/blog.ts     Formato de um artigo
  public/img/           Logo, fotos, ícone da aba e imagem de compartilhamento
  src/app/sitemap.ts    Gera o /sitemap.xml
  src/app/robots.ts     Gera o /robots.txt
  src/lib/seo.ts        Regras de SEO dos artigos (avisos no build)

Pontos de quebra (responsividade)
  acima de 1180px   desktop
  até 1180px        notebook pequeno
  até 980px         tablet (menu vira botão ☰ com gaveta lateral)
  até 600px         celular

Como ver no computador
  Requer Node.js 20.9 ou superior.
    npm install
    npm run dev        e abra http://localhost:3000

Como publicar
  Vercel (recomendado) ou Netlify: importe o repositório do GitHub; o
  build (npm run build) é detectado automaticamente. Defina a variável
  NEXT_PUBLIC_SITE_URL com o endereço final do site (ver .env.example).

Como editar textos
  Os textos de cada seção estão no arquivo correspondente em
  src/components/. Contatos e endereço ficam em src/lib/site.ts.

Equipe (bios das advogadas)
  Nome, OAB, formação e bio de cada advogada ficam em src/data/equipe.ts.
  Troque todo trecho "[PREENCHER]" pelos dados reais — enquanto houver
  pendências, o build avisa e as advogadas não entram nos dados de SEO.
  Fotos: public/img/equipe/advogada-1.jpg e advogada-2.jpg (hoje são
  recortes provisórios; ideal: retrato vertical 3:4, mínimo 900x1200px).
  Bios devem seguir o Provimento 205/2021 da OAB (tom informativo, sem
  autopromoção ou promessa de resultado).

Formulário de contato (envio de e-mail)
  O formulário usa o Resend (resend.com) para enviar as mensagens ao
  e-mail do escritório. Para ativar:
    1. Crie uma conta gratuita em resend.com (de preferência com o e-mail
       tondatoadvocacia@gmail.com) e gere uma API key.
    2. Na Vercel/Netlify (e no .env.local para testar), defina
       RESEND_API_KEY com essa chave.
    3. Opcional: verifique o domínio do site no Resend e defina
       CONTATO_FROM com um remetente desse domínio (ex.: contato@...).
       Sem domínio verificado, o Resend só entrega ao e-mail dono da conta.
  Sem a chave, o formulário aparece normalmente, mas avisa que o envio
  está indisponível e sugere o WhatsApp.

SEO (aparecer no Google)
  O site já gera automaticamente:
    - /sitemap.xml   lista de páginas e artigos para o Google (novos artigos
                     entram sozinhos)
    - /robots.txt    libera o site e informa o sitemap
    - título, descrição, endereço canônico e prévia para redes sociais em
      cada página; dados estruturados do escritório e de cada artigo
  Ao criar um artigo (src/data/posts.ts; depois, no Sanity), preencha:
    palavrasChave  lista de termos; o PRIMEIRO é o principal e deve aparecer
                   no título, no endereço (slug) ou no resumo
    capaAlt        descrição da imagem de capa
    seoTitulo      opcional; título para o Google (até 60 caracteres)
    seoDescricao   opcional; descrição para o Google (70 a 160 caracteres)
  Se algo estiver fora do ideal, o "npm run build" mostra um aviso [seo].
  Obs.: o Google não usa a meta tag de palavras-chave para ranquear; o que
  conta é o termo estar no título, no endereço e no texto do artigo.

  Google Search Console (fazer uma vez, após publicar):
    1. Acesse search.google.com/search-console e adicione o domínio do site.
    2. Escolha verificar por "tag HTML", copie só o código do content="..."
       e defina NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION na Vercel/Netlify.
       Publique de novo e clique em Verificar.
    3. Em "Sitemaps", envie: sitemap.xml
  Também recomendado: manter o Perfil da Empresa no Google atualizado
  (pesa muito nas buscas locais, como "advogado previdenciário Toledo").

Integração com o Sanity.io (próximo passo)
  Trocar o conteúdo das funções em src/lib/blog.ts por consultas GROQ
  (há um exemplo de query comentado no arquivo). Os componentes não
  precisam mudar.

Pendente
  Incluir o número de inscrição da sociedade na OAB/PR no rodapé
  (exigência do art. 44 do Código de Ética da OAB).
